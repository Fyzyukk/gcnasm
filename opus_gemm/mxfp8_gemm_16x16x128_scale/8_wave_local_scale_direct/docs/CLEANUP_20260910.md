## 可恢复备份

在任何移动/删除前，完整目录已打包，并通过`tar --compare`与原目录比对。
执行删除前再次核对归档SHA及整个原目录，未出现差异。归档位于父目录：

```text
../.8wave_cleanup_20260910.3fslk1/before_cleanup.tar.gz
SHA256 36dc9005a44809aabc6e7a667668ccb9589ad94acb04cbed19e9661cc14ce528
```

该路径以`8_wave_local_scale_direct/`为基准；不是docs目录的相对路径。
恢复时先解压到一个新的独立目录，不要覆盖当前整理后的代码：

```bash
# 从 8_wave_local_scale_direct/ 执行；只在确实需要历史材料时运行。
task_restore_dir=$(mktemp -d ../8wave_history_restore.XXXXXX)
tar -xzf ../.8wave_cleanup_20260910.3fslk1/before_cleanup.tar.gz -C "$task_restore_dir"
```

完整archive保留原始层级、旧版README/方案总览/总账、全部候选、原始配置、
源码快照及checker。此前所有源码为untracked，不能依赖git恢复；不要误删此
压缩备份。如果确认以后完全不需要历史材料，再单独决定永久删除备份。
